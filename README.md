# Painel de produtividade operacional

Este pacote contem o codigo completo do painel separado em arquivos.

## Arquivos

- `index.html`: estrutura da pagina.
- `style.css`: estilos e paleta visual.
- `script.js`: interacoes, tarefas, links e marcacoes do painel.

## Como abrir no computador

1. Abra a pasta `painel_codigo_completo`.
2. Clique duas vezes em `index.html`.
3. O painel vai abrir no navegador.

## Como hospedar no GitHub Pages

1. Crie um repositorio no GitHub.
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositorio.
3. Entre em `Settings`.
4. Va em `Pages`.
5. Em `Build and deployment`, selecione:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Clique em `Save`.

O arquivo principal precisa continuar com o nome `index.html`.
